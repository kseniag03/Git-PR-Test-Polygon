# Автоматизированный мониторинг и реагирование на угрозы

## Описание
Скрипт анализирует события сетевой безопасности из логов Suricata и проверяет IP-адреса через VirusTotal API.  
Скрипт использует относительные пути от директории самого файла `threat_monitoring.py`.
Реагирование реализовано в виде имитации блокировки IP-адресов и вывода уведомления в консоль.  
Дополнительно может быть подключена отправка email-уведомлений через SMTP при наличии переменных окружения.

## Используемые источники данных
1. Логи Suricata (`logs/eve.json`)
   - тестовые данные взяты из репозитория [suricata-sample-data](https://github.com/FrankHassanabad/suricata-sample-data)
2. API VirusTotal
   - API-ключ передаётся через переменную окружения `VT_API_KEY` (пример: `.env.example`)

## Что делает скрипт
- загружает alert-события из логов Suricata
- фильтрует события по уровню `severity`
- извлекает IP-адреса
- проверяет IP через VirusTotal
- определяет потенциальные угрозы
- имитирует реагирование (вывод сообщения о блокировке IP)
- сохраняет отчёт в CSV
- строит график top-5 IP по количеству alert-событий

## Параметры запуска
Скрипт поддерживает необязательный аргумент:

- `--max-severity` – максимальный уровень `severity` для анализа  
  По умолчанию используется значение `2`.

## Запуск

Запуск с параметрами по умолчанию:

```bash
python threat_monitoring.py
```

Запуск с указанием собственного порога severity:

```bash
python threat_monitoring.py --max-severity 1
```

## Переменные окружения
Для работы скрипта можно использовать файл `.env`, созданный на основе `.env.example`.

Основная переменная:
- `VT_API_KEY` – API-ключ VirusTotal

Дополнительные переменные для отправки email:
- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASSWORD`
- `EMAIL_SENDER`
- `EMAIL_RECIPIENT`

Если переменные для SMTP не заданы, почтовое уведомление будет пропущено без остановки скрипта.

## Выходные файлы
После выполнения скрипта создаются:

- `output/report.csv` – отчёт с результатами анализа
- `output/top_ips.png` – график top-5 IP по количеству alert-событий

## Формат отчёта
Отчёт сохраняется в формате CSV с разделителем `;` для корректного открытия в Excel.
